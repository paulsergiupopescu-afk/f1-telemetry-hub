# Original setup source material

`1.5/` contains the user-supplied Brendon Leigh setup package PDFs.

The application does not read or display these PDFs during normal use. Their
values have been normalized into `assets/brendon_leigh_setups_v1_5.json`, which
is what the Pre-Race screen renders directly. The PDFs are retained only as
source/reference material and are deliberately excluded from packaged builds.

`ocr_cache_v1_5/` is disposable import cache and can be regenerated by the
maintenance script.
